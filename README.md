# Peripheral Planner

Итоговый проект по практическим занятиям 13-18 по дисциплине "Фронтенд и бэкенд разработка". Все задания объединены в одно PWA-приложение на тему компьютерной периферии.

## Что реализовано

- Практика 13: список задач/заметок, сохранение в `localStorage`, регистрация Service Worker, офлайн-работа.
- Практика 14: `manifest.json`, PWA-мета-теги, набор PNG-иконок, кэширование manifest и иконок.
- Практика 15: архитектура App Shell, динамические страницы `Задачи`, `Периферия`, `О нас`, стратегия Network First для `/content/*`.
- Практика 16: сервер на Node.js/Express, Socket.IO, событие `newTask`, всплывающие WebSocket-уведомления, push-подписка и отписка.
- Практика 17: задачи с датой и временем напоминания, серверное планирование через `setTimeout`, push-напоминания, действие уведомления "Отложить на 5 минут".
- Практика 18: подготовлен README и единый репозиторий для сдачи контрольной работы.

## Запуск

```bash
npm install
npm start
```

После запуска откройте:

```text
http://localhost:3001
```

Если рядом с `server.js` находятся файлы `localhost.pem` и `localhost-key.pem`, сервер автоматически запустится по HTTPS. Их можно создать через `mkcert`:

```bash
mkcert -install
mkcert localhost 127.0.0.1 ::1
```

## Проверка

1. Откройте приложение и добавьте несколько задач.
2. Перезагрузите страницу: задачи останутся в `localStorage`.
3. В DevTools проверьте `Application -> Service Workers`, `Manifest` и `Cache Storage`.
4. Отключите сеть в DevTools и обновите страницу: App Shell и контент должны открыться из кэша.
5. Откройте вторую вкладку и добавьте задачу: в другой вкладке появится WebSocket-сообщение.
6. Нажмите "Включить уведомления", разрешите уведомления и создайте задачу с напоминанием на будущее.
7. В push-уведомлении для напоминания доступна кнопка "Отложить на 5 минут".
